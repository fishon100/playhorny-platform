# 06 新專案啟動

> 總覽：[00 總覽](00%20總覽.md)。照順序做，大約半天就能有第一個能在手機上玩的版本。

## A. 建 repo（程式負責，15 分鐘）

- [ ] 在 GitHub 打開 `game-dev-flow-template` → **Use this template** → 取新專案名稱（公開或私人都可以；免費帳號的私人 repo 不能用 GitHub Pages）
- [ ] 下載到本機：`gh repo clone <帳號>/<專案>`
- [ ] 安裝 Spectra 指令：`npm install -g @kaochenlong/spxa`，在專案資料夾執行 `spxa init --tools claude`
- [ ] repo 的 Settings → Pages → Source 選 **GitHub Actions**
- [ ] repo 的 Settings → Actions → General → Workflow permissions 選 **Read and write permissions**（工作台要寫回同意紀錄）
- [ ] 改 `workbench.config.json`（遊戲名稱、試玩網址；專案自己的工具放 `tools`，見 [08 工作台與遠端操作](08%20工作台與遠端操作.md) 的「專案工具（外掛）」）、`docs/spectra/config.yaml`（遊戲名稱、玩法、核心規則）、`.github/ISSUE_TEMPLATE/config.yml`（工作台網址）
- [ ] 對 AI 說「**檢查環境**」，全部 ✅
- [ ] 推上 GitHub → 到 Actions 看 `test-and-deploy` 與 `workbench` 都成功
- [ ] 打開工作台 `https://<帳號>.github.io/<專案>/workbench/`，手機加到主畫面
- [ ] （選用）手機推播：手機裝 ntfy App 訂閱一個難猜的主題；Settings → Secrets → Actions 新增 `NTFY_TOPIC`

## B. 建 Notion（選用，企劃負責，AI 幫忙，20 分鐘）

先用基本版（GitHub＋工作台）也可以，之後再加。→ [03 Notion 與 GitHub](03%20Notion%20與%20GitHub.md)
- [ ] Claude 連好 Notion 連接器，對 AI 說「**建 Notion 工作區**」→ AI 建好頁面與資料庫，把 ID 寫進 `docs/notion.json`
  - 還沒連接器？用 `docs/notion-import/` 的 CSV 手動匯入（步驟在 03 的「用 CSV 匯入」），之後再說「接上 Notion 工作區」
- [ ] 填專案首頁的帳號表（[05 工具與帳號](05%20工具與帳號.md)）

## C. 寫核心（企劃負責，1～2 小時）

- [ ] 寫「主架構規劃書」：一句話、設計支柱（3～5 個）、核心循環、**不能改的核心規則**（Notion 或 `docs/企劃/`）
- [ ] 對 AI 說「**把主架構規劃書的核心規則抄進 config**」：AI 寫每張提案時都會讀到，碰到核心規則會在「需要企劃確認的事」第一條警告你
- [ ] 知識庫先建「名詞表」：遊戲裡每個東西的正式名稱
- [ ] 邀請團隊成員：GitHub repo（Settings → Collaborators，給 Triage 以上就能勾同意、寫回饋）、Notion 工作區
- [ ] 工作台「提需求」丟第一批想法

## D. 第一個可玩版本（AI，1～2 小時）

- [ ] 對 AI 說：`/goal 依主架構規劃書，開第一張提案做出可玩的核心循環，企劃同意後實作，測試全過、部署並通知`
- [ ] AI 會：寫提案 → 推上去（自動開提案 Issue）→ **等你在工作台同意** → 實作 → 部署 → 手機通知
- [ ] 手機試玩，工作台「寫回饋」→ 對 AI 說「看回饋」

## E. 進入循環

從這裡開始就是 [01 一輪開發](01%20一輪開發.md) 的循環。建議節奏：
- 每天：企劃打開工作台首頁「需要你處理」、試玩
- 每週：團隊一起看工作台「提案」與「上線紀錄」；說「備份」
