## 換一台電腦（叫 AI 做事的那台）

雲端的東西（工作台、GitHub、Notion）**不受影響**，只有「AI 那台電腦」要準備：

- [ ] 安裝 Node.js 22 以上、git、GitHub CLI（gh）
- [ ] 安裝 Spectra：`npm install -g @kaochenlong/spxa`（要桌面版的話另外下載）
- [ ] 下載專案：`gh repo clone <帳號>/<專案>`，在專案資料夾執行 `spxa init --tools claude`
- [ ] 在 Claude Code 打開專案資料夾，說「**檢查環境**」→ AI 執行 `node tools/doctor.mjs`，缺什麼會告訴你怎麼補
  - GitHub 要登入時，AI 會在它的終端機產生一組代碼，你到 https://github.com/login/device 輸入、按 Authorize
  - ⚠️ 你自己開的終端機和 Claude 的終端機可能是**分開的**：授權一律請 AI 發起
- [ ] 說「**檢查連接器**」確認 Notion／Figma／Drive 帳號正確
- [ ] （選用）本機設定檔：`tools/notify.config.json`、`tools/backup.config.json`（不在 git 裡，要重填）
- [ ] 企劃、美術等人換電腦：打開管理台，右上角重新「登入」一次就好

## 換 Claude 帳號／換人接手

- [ ] 新帳號連好 Notion、Figma、Google Drive 連接器，說「檢查連接器」確認帳號正確
  - 連接器出現「Account mismatch」：瀏覽器登入的 claude.ai 帳號和 Claude Desktop 不同 → 用同一個帳號（可開無痕視窗）
- [ ] 說「檢查環境」
- [ ] 讀 `CLAUDE.md`、工作台、開發日誌最後 5 筆，就知道做到哪
- [ ] 更新上面的帳號表

## 確認 Claude 連到哪些工具

說「**檢查連接器**」：AI 列出每個工具的連線狀態，並實際讀一樣東西確認**帳號是對的**（例如雲端硬碟裡找得到專案資料夾）。帳號不對就停下來，不會在別人的雲端硬碟或工作區裡搜尋。

## 密鑰規則

- 不放進 git：ntfy 主題、API 金鑰、個人設定檔（`.gitignore` 已經擋了 `tools/*.config.json`）
- 放 GitHub Secrets：CI 要用的（`NTFY_TOPIC`）
- 公開 repo 也不要寫本機路徑、個人 email
